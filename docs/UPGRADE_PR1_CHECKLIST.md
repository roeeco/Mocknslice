## Existing files to inspect, initially leave unchanged

- `src/geometry/folding/netBuilder.ts`, `generateFoldTemplate.ts`, `connectionEditing.ts`, `validateFoldConnections.ts`: true seam geometry, explicit physical connection pairs, tab-expanded cut contours, last-valid output.
- `src/geometry/connections/topology2d.ts`: existing rigid alignment, contour tracing and tab predicates. Reuse verified pure predicates rather than adding contradictory geometry rules.
- `src/geometry/panelConstruction/generatePanelConstruction.ts`: actual `interlocking-panel-fingers-v8` result, 12 shell/lid connection keys (the plan's “eight” description predates lid keys), role stock and face receiver joints.
- `src/domain/folding.ts`, `panelConstruction.ts`, `unfolding.ts`, `connections.ts`, `fabrication.ts`: current IDs and metadata. `PanelConstructionResult` can already represent creased multi-panel components, not always one part per panel.
- `src/state/slices/selectionSlice.ts`, `src/state/types.ts`: existing `selectEntity(id, ownerPartId)` remains runtime-only; identity map must fit it without creating another selection authority.
- `src/domain/generationInputs.ts`, `generation.ts`: signature version 2 and active-only canonical inputs remain untouched in PR 1.
- `src/workers/protocol.ts`, `geometry.worker.ts`, `geometryWorkerClient.ts`: retain all request types, cancellation, captured hash and stale rejection. Worker graph integration comes later.
- `src/exporters/importProject.ts`, `exportProject.ts`, `exportSvg.ts`, `exportPdf.ts`, `src/persistence/database.ts`: keep current v8 data and byte-level export parity; no early schema bump.
