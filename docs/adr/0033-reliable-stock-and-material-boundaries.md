# ADR 0033: Native stock geometry and preserved arrangement

The historical pure generators remain the literal inspection oracle. Worker dispatch now uses separately versioned reliable wrappers. Stacked slices reject open/ambiguous intersections and overlapping thickness; oriented coplanar arrangements resolve valid closed boundary slices without bridging gaps. Registration holes share actual source coordinates and require stock ligaments. Waffle U notches replace the exterior mouth arc, retain paired guides, and validate partner stock, insertion access and ligaments.

Panel generation is mechanically decomposed into specification, joints, assembly, features and validation modules. Native finger boundaries use material union/difference; only zero-area legacy corner retraces are removed. Untraceable boundaries block generation. Scored components use polygon union because a cleaned contour can span several nominal edges. Reciprocal joints validate references, spans, stocks and complementary relief. Per-role kerf and clearance remain optional; legacy input/default output is unchanged.

Quick rows remain the default. Regeneration retains stable placements and reports conflicts rather than silently repacking. Optional deterministic MaxRects uses 0/90-degree rotation subject to grain policy, preserves arbitrary locked transforms, and verifies actual polygon output. Different stock thicknesses receive separate sheets; mixed locked stocks require explicit correction.

No physical calibration is implied. New geometry receives version-3 provenance and the common prepared-output preflight. Existing literal goldens, including known defects, are unchanged.
