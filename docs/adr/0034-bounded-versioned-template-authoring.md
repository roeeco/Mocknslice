# ADR 0034: Version locked definitions and native template contours

Custom definitions are pure data: numeric literals, parameter references, and add/subtract/multiply/divide/min/max/clamp AST nodes. There are no executable strings, property access, external images or remote fetches. Limits are 16 expression levels, 2,000 evaluated nodes, 32 parameters, 200 panels, 199 hinges, 200 tabs/marks, 100 vertices per polygon and a 2 MiB definition file. Cycles, invalid references, nonfinite values, zero denominators, overlapping flat panels/tabs, invalid holes and untraceable cutting boundaries fail before application.

A custom graph explicitly owns polygons, holes, hinges, closure edges, tab guides, score features, labels and rigid numeric assembled poses. Physical boundaries come from their material union/difference and compile through the common graph compiler. The original cross-tray seed supports adjustable width/length/height and editable bounded JSON topology. Features survive dimension changes. The UI provides creation, saved variants, clone, reset, alternative dimensions, JSON editing and definition import/export in both languages.

Projects embed exact definitions and instance values with definition hashes. Saved definition versions are immutable; changes require a new version or identity. IndexedDB version 2 adds a template store without replacing project records, settings or the last autosave pointer. Import validates the graph and compares current caches against the locked definition; older inspection results remain unchanged. Library updates never silently change open projects.

Native built-in template generation retains the historical pure engine as the inspection oracle, then compiles closed material boundaries, normalizes graph winding and fits tabs against actual panel geometry. Native coordinates share the existing 1e-6 mm rounding grid, avoiding artificial positive intersections between independently rounded tab bases and unrounded trigonometric panels. Legacy per-piece cap reference failures are resolved only when the global panel inventory proves the referenced partners exist. Edited components use their own flat transforms and stable piece identities. Original goldens are untouched.

Press-fit receiver slits remain explicitly inspectable legacy geometry until the separate physical receiver track is verified. They are never converted into fake closed slots or silently omitted from cutting operations. Five existing construction recipes are registered through their actual generator and validated graph metadata, with original generated previews. No unsupported FEFCO entry is added and no design is marked physically verified.
