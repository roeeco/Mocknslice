# ADR 0035: Accepted source updates and durable papercraft intent

Source replacement is a proposal, not an immediate overwrite. A typed worker prepares the proposed mesh, and a focus-managed, bilingual review dialog reports matched and unresolved edits. Cancel retains the original project. Accept records the replacement and all transferred/unresolved intent in one undo transaction. Undo, project replacement and cancellation invalidate pending workers; a late result cannot overwrite another project or source.

Relinking replays identical mesh hashes exactly. Otherwise it requires mutual, unique face matches within 0.1 mm with normals within 5 degrees, corresponding edges within 0.1 mm and 2% length, and consistent adjacent faces. A reversed A/B correspondence reverses tab ownership. Island anchors require at least 70% mapped source faces. Ambiguous or missing matches become persistent, schema-validated unresolved records. Unmatched island placement is removed from the new layout rather than being accidentally reused through a coincident identifier. Production output remains blocked until each record is explicitly remapped or discarded; old intent remains available for review.

Accepted simplification stores a serializable working mesh alongside the unmodified original source. Its preparation hash locks source identity, target and deviation settings. Further seam and tab changes use that mesh, preserving face/edge identity. Re-preparation is explicit and goes through the same review gate. v9 import validates mesh hashes, bounds, topology and result correspondence; native fields cannot be smuggled through older migration branches.

Conservative native QEM retains sharp-edge coordinates across vertex compaction and rejects trial collapses that violate manifold preflight, body Euler characteristics or winding. These guards are opt-in: historical QEM callers retain their original behavior and inspection goldens. A continuous, symmetric surface-deviation bound uses nearest-triangle BVHs, the 1-Lipschitz distance bound and recursive triangle subdivision. Coplanar coverage uses the shared tolerance-aware polygon subtraction rather than an area-sum shortcut that could miss small holes. Failure to prove the bound rejects the mesh; sampled points alone cannot authorize it. Cached meshes undergo the same proof. Native preparation supports at most 5,000 source triangles; output target is 4–200 triangles. Surface proof is bounded by 200,000 distance queries and depth 10. Optional search/preparation has a six-second deadline checked between operations, not a hard wall-clock guarantee for each individual polygon operation. Worker termination provides hard cancellation.

Search seeds exclude automatic/tab-only preferences and the accepted-mesh cache, preventing a tab correction from needlessly changing the hinge forest. Actual canonical input hashes still include all geometry-affecting data. A transient failed candidate exposes unresolved tab ownership/suppression controls while retaining the last valid artifact. Editing a simplified candidate first accepts its working mesh in the same history transaction.

Rigid fold poses interpolate from separated ground-plane islands to the original source orientation and body spacing. This preserves disconnected bodies and rotated sources. GPU face buffers remain keyed to source geometry; fold progress changes transforms. Renderer-only constrained triangulation correctly fills concave panels and excludes holes. The preview explicitly does not certify a collision-free assembly sequence.

Source/preparation settings use buffered controls with one commit per completed edit. Project load selects an occupied sheet when available. Autosave checks project identity at timer start and completion, does not erase edits/history when hydration arrives late, and preserves the last saved record after a failed load until a new user edit. Invalid imports and failed workers retain the current project and previous valid output.

Legacy wizard and triangle unfolding remain available. Removing either requires a separate migration-parity review and ADR. Digital checks do not certify physical assembly or material fit, and this work does not introduce FEFCO catalog entries.
